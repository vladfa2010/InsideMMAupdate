# InsideBroker Update

Публичный репозиторий для дистрибутивов и сайта InsideBroker.

- **Сайт:** https://vladfa2010.github.io/InsideMMAupdate
- **Последняя версия:** 1.0.3

## Содержимое

- `index.html` — лендинг с кнопкой скачивания.
- `style.css` — стили сайта.
- `dist/InsideBroker_1.0.3.zip` — последний дистрибутив.
- `version.json` — информация о версии для автообновления внутри приложения.

## Исходный код

Исходный код приложения находится в отдельном приватном репозитории и не публикуется.

## Установка

1. Скачайте `dist/InsideBroker_1.0.3.zip`.
2. Распакуйте в любую папку.
3. Запустите `InsideBroker.exe`.

## Автообновление

InsideBroker проверяет `version.json` при запуске и предлагает обновиться, если доступна новая версия.

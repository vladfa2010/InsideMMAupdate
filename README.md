# InsideMMA Update

Публичный репозиторий для дистрибутивов и сайта InsideMMA.

- **Сайт:** https://vladfa2010.github.io/InsideMMAupdate
- **Последняя версия:** 1.0.0

## Содержимое

- `index.html` — лендинг с кнопкой скачивания.
- `style.css` — стили сайта.
- `dist/InsideMMA_1.0.0.zip` — последний дистрибутив.
- `version.json` — информация о версии для автообновления внутри приложения.

## Исходный код

Исходный код приложения находится в отдельном приватном репозитории и не публикуется.

## Установка

1. Скачайте `dist/InsideMMA_1.0.0.zip`.
2. Распакуйте в любую папку.
3. Запустите `Inside MMA.exe`.

## Автообновление

InsideMMA проверяет `version.json` при запуске и предлагает обновиться, если доступна новая версия.
